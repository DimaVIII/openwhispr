# Android acceptance matrix

Work in progress. The ARM64 development APK embeds its JavaScript; launch and inference were exercised with airplane mode on, Wi-Fi off and no Metro reverse port. The retained emulator reached its PIN screen before the final interactive pass. That pass remains pending a normal device unlock. Current source passes TypeScript, 266 Jest suites / 3,015 tests, changed-file ESLint (0 errors), locale key/interpolation validation and the ARM64 release build. A native-initialization regression fails before the fix and passes after. Synthetic audio, silent recorder lifecycle, emulator UI, live authentication and physical-device testing are separate evidence.

The source audit also found Translate, Write and Edit cleaning speech before discarding that output and performing the requested action. They now use raw transcription followed by one text action. Nine regression cases reproduced the extra pass across local, cloud and BYOK routes before the fix; all pass after it. Ordinary dictation cleanup remains covered. This change still needs emulator timing and action-flow verification after normal unlock.
